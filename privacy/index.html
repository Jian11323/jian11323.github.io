隐私政策

最近更新日期：2026-10-02 ｜ 版本：1.6

欢迎您使用 Jian Project（以下简称“我们”或“本站”）的服务。我们重视您的隐私，并将按照《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》等适用法律，以合理方式处理与保护相关信息。本政策说明我们如何收集、使用、存储和保护您的信息。您继续使用本站，即表示已阅读并同意本政策；如不同意，请停止使用。

本站为个人学习与技术研究用途。浏览公开文档与页面通常无需实名账号；申请接口访问令牌时，您可自愿通过鉴权站点提交邮箱。管理后台账号仅限内部授权使用。

关于服务可用性、连续性、及时性与准确性等保证限制，以及服务可能随时终止等约定，详见《服务条款》。本站 API 及相关推送属于公益服务，仅限学习测试场景使用；您使用本服务即表示已知悉并自愿承担相关风险。

严禁二次转发：未经本站书面授权，禁止将本站接口、推送数据或服务以任何形式二次转发、再分发、代理中转、转售或以其他方式向第三方提供。我们可能据此采取限连、封禁等措施，详见《服务条款》。

一、我们收集的信息

当您使用我们的服务时，我们可能收集以下类型的信息：

  • 您主动提供的信息：如您通过鉴权站点（auth.sismotide.top）申请访问令牌，我们会收集您填写的 QQ 系邮箱（如 @qq.com / @foxmail.com / @vip.qq.com），用于发送登录密钥与处理申请。如您因联系站长或反馈问题自愿提供其他联系方式，相关信息仅用于沟通与处理问题。
  • 令牌与鉴权相关信息：为核验与防滥用，我们可能保存邮箱标识、令牌哈希（不以明文长期保存访问/长期令牌正文）、签发与吊销状态、配额与申请频次等必要记录。
  • 自动收集的信息：为维护服务运行与安全，服务器可能自动记录 IP 地址、访问路径与端口、连接与断开时间、浏览器或客户端类型（User-Agent）及必要的服务日志。本站不主动收集身份证号、银行卡号等敏感个人信息，亦不面向公众提供实名完善资料或在线支付。
  • 管理操作记录：后台登录、IP 封禁 / 解封、访问策略与密钥管理等操作可能保留审计记录（操作者、时间、目标对象）。

本站未主动设置用于广告投放或跨站行为追踪的 Cookie。浏览器本地可能保存您是否已阅读「使用须知」等偏好（如 sessionStorage / localStorage），此类信息不单独用于画像或广告。连接层技术信息仍可能按上文被记录。

二、我们如何使用信息

我们收集信息的目的在于：

  • 提供、维护和改进本站服务（含文档、WebSocket / HTTP 接口、鉴权发钥与换票）；
  • 保障服务安全，预防滥用、攻击或欺诈行为（包括限连、黑白名单、申请配额等）；
  • 进行故障排查、运维审计，并在法律要求时配合有权机关；
  • 遵守相关法律法规的要求。

一般连接与审计日志按运维需要保留，以可追溯滥用行为为限，过期后可定期清理。黑名单、令牌哈希与策略数据在规则有效、令牌有效或管理员删除前持续保存。

三、信息的保护

我们采取合理的技术与管理措施（如 HTTPS、访问控制、管理账号与令牌哈希存储、最小权限等）保护相关信息，防止未经授权的访问、披露、使用、修改或损坏。但请您理解，由于技术限制及可能存在的恶意手段，互联网环境无法保证信息百分之百安全。

请妥善保管您的邮箱收件箱中的登录密钥与令牌，勿转发或公开。若您不希望连接信息或邮箱被用于上述目的，请勿使用本服务或申请令牌。如认为 IP 被误封，可通过站点联系渠道申诉。未成年人应在监护人指导与同意下使用本站。

四、与第三方共享信息

我们承诺不会将您的个人信息出售、出租或以其他方式与任何无关的第三方共享，除非：

  • 已获得您的明确同意；
  • 根据法律法规、法律程序或政府主管部门的强制性要求；
  • 为维护公共利益，或保护我们及用户的合法权益所必需。

为发送登录密钥，我们可能通过邮件服务基础设施投递至您提供的邮箱；邮件传输过程适用相关服务商的处理规则。本站文档中的第三方链接或接口地址仅供技术说明；您访问第三方服务时，适用对方的隐私政策，本政策不适用于第三方。

五、隐私政策的更新

我们可能会适时修订本隐私政策。当政策发生变更时，我们会在本页面发布更新后的版本，并以本页「最近更新日期」为准。我们鼓励您定期查看本页面。如您在政策修改后继续使用本站，即视为已接受修改后的政策。
