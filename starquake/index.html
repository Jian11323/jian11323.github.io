软件简介

StarQuake 是面向 Windows / Linux 的地震预警与速报视监客户端。把多源实时情报汇总到同一主界面：侧栏浏览情报，地图叠加震中与走时波圈，并可配置本机位置估算 S 波倒计时。

建议运行环境为 64 位系统；使用 Jian 数据通道时需在设置中配置访问令牌（邮件自助申请）。

能做什么？

  • 接收 CEA / CWA / JMA / KMA 等地震预警，以及 CENC / JMA 等速报与列表。
  • 展示海啸情报、台风路径；测站烈度（NIED / S-Net / KMA 等）可在列表与地图色点查看。
  • 暗色矢量底图 / 亮色海洋地形瓦片，可随主题切换；支持多语言界面。
  • 本机 S 波倒计时与抵达提示音；非 JMA 预警按烈度≥7 或 M≥5 播危急档，否则普通预警音；JMA 用 SREV；速报独立提示。
  • 设置页可配置数据源、地图、音频、性能与高级选项。
