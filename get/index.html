Jian Project GET 服务

HTTPS GET UTF-8 JSON 每 IP ≥1 次/秒

IP 归属查询、国内雷达、云图、降水预报、台风、气象站、AQI、台湾省雷达、日本雷达、全球热带气旋与风场。适合学习与对接调试。

基础地址：/api/get

请求方式：GET /get/[路径].php，例如 /get/radar.php

鉴权：不需要访问令牌。防滥用见 频率限制。

编码：UTF-8 JSON

说明：本页为 GET API 字段说明；响应为 HTTPS GET JSON。

单端点 /get/[路径].php

通用约定

  • 全国最新雷达 / 云图 / 日本雷达：带图片与地图范围；全国最新降水预报：可叠地图的降雨区域；全国最新城市 AQI 指数：城市列表。
  • size 为图像像素尺寸；time 为时次（北京时间）。
  • 缺字段省略，不补 0 或空串。
  • 响应格式见 消息协议；各路径字段见侧栏对应章节。
  • 仅供学习研究，不保证稳定性。

频率限制

本服务不需要访问令牌。为防滥用，按客户端真实 IP 做请求频率限制（经 CDN 时取 CDN / X-Forwarded-For 规则与站内一致）。

默认限额

项目 规则
最小间隔 同一客户端 IP 对业务路径至少间隔 1 秒 1 次
计入路径 /get/ip.json、/get/radar.json、/get/cloud.json、/get/precip-forecast.json、/get/typhoon.json、/get/typhoon-global.json、/get/wind.json、/get/station.json、/get/aqi.json、/get/radar-japan.json、/get/radar-taiwan.json 等业务 GET
不计频 /health 健康检查不计入上述间隔

超限响应

超过频率限制时返回 HTTP 429，正文为 JSON：

请求过于频繁
{
  "error": "请求过于频繁，请至少间隔 1 秒"
}

对接建议

  • 客户端应对图片 / 列表结果做本地缓存，避免无意义轮询。
  • 收到 429 后应退避重试，勿瞬时连打。
  • 更多说明见 服务条款 与 隐私政策。

IP 归属查询 GET API 字段说明文档

请求地址：/get/ip.php

说明：查询 IP 归属地

示例

{
  "ip": "222.137.1.1",
  "country": "中国",
  "country_code": "CN",
  "province": "河南",
  "city": "郑州",
  "district": "金水",
  "isp": "电信",
  "lat": 34.757,
  "lon": 113.649,
  "location": "中国·河南·郑州·金水·电信",
  "division_code": 410105
}

字段说明

字段名类型必填说明
ip string 是 查询的 IP
skipped bool 否 私网/回环等不可查时为 true
country string 否 国家中文名
country_code string 否 ISO 3166-1 alpha-2
province string 否 省/州
city string 否 城市
district string 否 区县
isp string 否 运营商
lat number 否 纬度
lon number 否 经度
location string 否 地名拼接摘要
division_code number 否 大陆行政区划代码
error string 否 参数错误说明

注意事项

  • GET；无需令牌。
  • 同一 IP 至少间隔 1 秒。
  • 大陆命中时省市区与 lat/lon 同源（区划中心点），不与全球库经纬度混拼。
  • 仅供参考，不对准确性做保证。

实时台风 GET API 字段说明文档

请求地址：/get/typhoon.php

说明：获取当前西太平洋及南海活跃台风

示例数据

[
  {
    "id": "202625",
    "name": "杜鹃",
    "name_en": "DUJUAN",
    "latitude": 38.2,
    "longitude": 147.4,
    "moveDirection": "东北东",
    "moveSpeed": 50,
    "power": 10,
    "pressure": 985,
    "windSpeed": 25,
    "type": "强热带风暴",
    "radius7": "400|300|300|300",
    "updateTime": "2026-09-22 08:00:00",
    "points": []
  }
]

字段说明

字段名类型必填说明
id string 是 台风编号（如 202625）
name string 否 中文名
name_en string 否 英文名
latitude number 否 中心纬度
longitude number 否 中心经度
moveDirection string 否 移向
moveSpeed number 否 移速 km/h
power integer 否 中心附近最大风力等级
pressure integer 否 中心气压 hPa
windSpeed number 否 中心附近最大风速 m/s
type string 否 强度等级文案
radius7 number|string 否 七级风圈；四象限时为原样字符串如 400|300|300|300
radius10 number|string 否 十级风圈；规则同 radius7
updateTime string 否 最新实况点时间（北京时间）
points array 否 完整实况路径点（有则保留）

注意事项

  • 响应为 JSON 数组；无活跃台风时为 []。
  • 缺字段则省略，不填 0 或空串。
  • 四象限风圈不压成单个假半径。
  • GET；无需令牌；同一 IP 至少间隔 1 秒。

全国气象站 GET API 字段说明文档

请求地址：/get/station.php?type=temperature

说明：获取全国气象站指定要素（含台湾省）；type 必填，type=all 返回该站全部可用要素

示例数据

{
  "time": "2026-09-22 11:00",
  "count": 3200,
  "data": [
    {
      "sta_name": "北京",
      "stationid": "54511",
      "lat": "39.8",
      "lon": "116.47",
      "val": "25.8"
    },
    {
      "sta_name": "臺北",
      "stationid": "466920",
      "lat": "25.039439",
      "lon": "121.506628",
      "val": "29.5"
    }
  ]
}

字段说明

字段名类型必填说明
time string 是 时次（北京时间）
count integer 是 本响应 data 条数
data array 是 站点数组
sta_name string 是 站名
stationid string 是 站号
lat string 是 纬度
lon string 是 经度
val string 条件 单要素查询时的数值；type=all 时不使用此字段
fx string 否 风向角度（风速类可能出现）
temperature string 否 type=all 时的气温
pressure string 否 type=all 时的气压
humidity string 否 type=all 时的相对湿度
windspeed string 否 type=all 时的风速
rain string 否 type=all 时的降水
visibility string 否 type=all 时的能见度

注意事项

  • type 必填：temperature / pressure / windspeed / maxwindspeed24h / humidity / visibility / rain / all。
  • type=all 时展开各要素；缺测字段省略。
  • 含台湾省站点；同站号去重保留一条。
  • 缺测值（如 -99）不出现在响应中。
  • maxwindspeed24h 暂不可用时 data 可能为空数组。
  • GET；无需令牌；同一 IP 至少间隔 1 秒。

radius10 number|string 否 十级风圈；规则同 radius7
updateTime string 否 最新实况点时间（北京时间）
points array 否 完整实况路径点（有则保留；NHC 直拉补源可能无此字段）

注意事项

  • 响应为 JSON 数组；无活跃风暴时为 []。
  • 不含西北太平洋与国内台风；国内/西太请用 /get/typhoon.php。
  • GET；无需令牌；同一 IP 至少间隔 1 秒。

字段说明

字段名类型必填说明
status string 是 成功时为 success
time string 是 风场有效时刻（北京时间）
source string 是 固定为 gfs
resolution_deg number 是 水平分辨率（度），当前为 1
level string 是 高度层，如 10m
nx integer 是 经向格点数
ny integer 是 纬向格点数
data array 是 长度 2：依次为 U、V 分量，形态兼容 leaflet-velocity / grib2json
data[].header object 是 格点头：nx/ny/lo1/la1/lo2/la2/dx/dy 等

  • 同一 IP 至少间隔 1 秒；超限返回 429。

  • data 数组可直接交给 leaflet-velocity 等粒子风场组件。
