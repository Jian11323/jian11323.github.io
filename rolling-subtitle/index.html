Rolling-Subtitle

地震情报实况栏

Desktop Live Ticker · Open Source

基于 Python / PyQt5 的 Windows 滚动字幕工具：通过 WebSocket 与 HTTP 聚合多源情报，在屏幕上实时展示地震预警、速报、海啸、火山与气象等信息，并可选用 TTS、NHK/JMA 专属提示音与系统通知。当前版本 v2.9.0。

软件简介

地震情报实况栏（Rolling Subtitle）是一款 Windows 桌面端滚动字幕程序：把多个数据源的情报汇到同一条实况栏里，方便副屏或桌面常驻查看。程序基于 PyQt5，数据在本机处理；详细使用说明见仓库 Wiki。

建议运行环境为 Windows 10 及以上，具备稳定网络以访问所启用的数据源。

能做什么？

  • 以滚动字幕展示地震预警、速报、海啸、火山与气象预警等信息。
  • 主数据源可在 WeJet、Jian Project 中二选一；并可叠加 FSSN、Wolfx、EQSC、P2PQuake 等辅助源与国际速报源。
  • 可自定义界面样式与颜色，支持 NHK 一级新闻铃、JMA 警報音、TTS、系统通知，以及低 / 中 / 高 / 极致性能预设。
  • 提供完整日志；打包版支持自动检查更新。

数据来源

  • 日本气象厅地震情报、海啸情报：P2PQuake API。
  • 日本地震预警（JMA）：Wolfx、WeJet、Jian Project。
  • 中国地震预警 / 速报：中国预警网、中国地震台网中心、Jian Project。
  • 气象预警：中央气象台、WeJet、Jian Project。
  • FSSN：FSSN WebSocket API（地震信息与矩心矩张量解）。
  • 其他机构速报：USGS、EMSC、HKO、GFZ、USP、CWA、KMA、BMKG、GeoNet、INGV、PTWC 等（经聚合源或官方直连）。
  • 全局辅助源：FSSN、EQSC、台风、CENC 烈度速报、P2PQuake 等，可与任一主源并用。

更新说明 v2.9.0

  • 移除已停运的 Fan Studio 主数据源及相关登录鉴权，主数据源改为 WeJet 与 Jian Project 二选一。
  • 新增 FSSN 辅助源，支持地震信息与矩心矩张量解，矩张量解可显示震源机制沙滩球。
  • WeJet 新增中国地震台网烈度速报、GFZ 矩心矩张量解、委内瑞拉地震研究中心、自然灾害风险预警中心、新加坡国家环境局、日本气象厅冲合海啸观测等解析。
  • Jian Project 的 JMA 预警补充警报/预报、长周期地震动与警报区域，并跳过训练报。
  • P2PQuake 不再解析紧急地震速报（556），保留地震情报（551）与海啸预报（552）。
  • 告警音改为 NHK 一级新闻铃与 JMA 緊急地震速報警報提示音，可单独开关；通用有感/强震提示音改为语音播报（TTS）。
